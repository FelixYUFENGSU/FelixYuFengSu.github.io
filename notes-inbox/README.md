# Notes inbox

Upload scans of handwritten notes here and they're transcribed to Markdown + LaTeX
automatically. A pull request opens with the draft for you to check before it's published.

**One folder per course, one subfolder per lecture:**

```
notes-inbox/
  Real Analysis/
    2026-11-20 Cauchy sequences/     ← one note (pages in filename order)
      page1.jpg
      page2.jpg
    lecture14.pdf                    ← a scanned PDF is one note
  Probability/
    IMG_0412.HEIC                    ← loose photos in a course folder become one note
```

- Accepted: JPG, PNG, HEIC (iPhone photos), WEBP, and PDF.
- Start a lecture folder's name with a date (`2026-11-20 ...`) to date the note; otherwise
  it uses the upload date.
- **From a computer:** open this `notes-inbox` folder on GitHub, click **Add file → Upload
  files**, and drag in a whole course folder (with the lecture folder inside it). GitHub keeps
  the folder structure. Then **Commit changes**.
- **From your phone:** use the GitHub app or the mobile website the same way, or save scans
  to a computer first.
