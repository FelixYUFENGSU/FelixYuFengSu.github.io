Lab work from **CS 111 (Operating Systems)** at UCLA, all written in C. Each lab builds one real piece of how an operating system works.

## 1. A kernel seedling

A loadable **Linux kernel module** that adds a `/proc/count` entry reporting how many processes are running. It uses the kernel's procfs interface, module loading and unloading, and walks the process table with `for_each_process`.

## 2. Pipe up

A reimplementation of the shell's **pipe operator** (`|`): it runs a sequence of programs, feeding each one's output into the next one's input.

## 3. You spin me round robin

A **round-robin CPU scheduling** simulator. Given a list of processes and a time quantum, it schedules them and reports the average waiting time and response time.

## 4. Hash hash hash

Three versions of a **hash table**: a serial baseline, a thread-safe version with one global lock, and a thread-safe version with **fine-grained locking**. The versions are compared for speed and correctness under many concurrent inserts.

## 5. Hey! I'm filing here

Builds a valid **ext2 file system image** from scratch: the superblock, block and inode bitmaps, inode table, and directory structure, with a root directory, `lost+found`, a `hello-world` file, and a `hello` symlink. The image passes `fsck.ext2`.
