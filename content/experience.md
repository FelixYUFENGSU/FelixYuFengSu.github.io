## Latitude Machinery Corp.
role: Backend & Data Developer
when: Jun.–Sep. 2025
tags: Python, MySQL, Data migration, Web performance

Latitude Machinery builds machines for the corrugated cardboard box industry. Their website was a set of static HTML pages, and the specs for their machines lived in an Excel file, so the site couldn't really help prospective buyers. I rebuilt the data side of it.

- Designed a MySQL database for the company's machine models, their specs, the site's bilingual page content and customer inquiries, then moved everything over from the Excel file and the old pages.
- Wrote the Python backend that serves that data to the 7-page bilingual site, and was the person responsible for all of the site's backend data.
- Tracked down why pages loaded slowly: oversized images, some up to 2.4 MB each. Resizing and compressing them brought the total page weight from about 11.5 MB down to 1.2 MB, measured before and after.
- Also helped on the finance side, working as a data analyst on the company's numbers.

## Mammoth Cyber
role: AI Engineer
when: Nov. 2022–Feb. 2023
where: San Francisco, CA
tags: LangChain, Vertex AI, Elasticsearch, Prompt design

Worked on a feature that let users ask questions about their data in plain English instead of writing queries.

- Built the layer that translates a natural-language question into an Elasticsearch SQL query, using LangChain and Google Cloud's Vertex AI, so it worked across data sources with different schemas.
- Wrote reusable prompt templates and tested them with the engineering team, which reduced misread questions by about 20%.
